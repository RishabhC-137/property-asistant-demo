# Demo project catalogue

The 50 fictional cases in this folder are the shared source for the demo API,
Gemini property-search tools and deterministic mock provider. The web gallery
loads project cards from the API; it does not keep a separate project list.

The catalogue covers apartments (including studios), villas, offices, retail,
residential plots and warehouses around Gurugram and Sohna.

The names, developers, prices, amenities, locations, availability and payment
terms are invented for UI demonstrations. They are not real listings or
investment guidance; RERA references are intentionally left blank. Locations
and map positions are illustrative. The sample photos load from Unsplash and
require an internet connection.

Try a project search or comparison, then ask for project details, photos, its
payment plan or its location to exercise the other structured chat blocks.
