# Mock project showcase

These four fictional cases are used by the deterministic mock provider:

- **Aster Vale** — premium apartments under construction
- **Morrow Grove** — ready-to-move apartments
- **Cedar Courtyards** — low-rise villas at launch
- **Meridian Workyards** — commercial offices

The names, developers, prices, amenities, locations, availability and payment
terms are invented for UI demonstrations. They are not real listings or
investment guidance; RERA references are intentionally left blank. The sample
photos load from Unsplash and require an internet connection.

Try a project search or comparison, then ask for project details, photos, its
payment plan or its location to exercise the other structured chat blocks.
